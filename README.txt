FIRSTAID.exe offline app package

1. Upload this whole folder to any HTTPS host (Netlify Drop, GitHub Pages, Cloudflare Pages).
2. Open the link once with internet. The app saves itself.
3. Android Chrome: tap INSTALL APP. iPhone Safari: Share, then Add to Home Screen.
4. After that it opens and runs with no internet. The "ask anything" search still needs internet.

Voices: the app uses the voices already installed on the phone. Yoruba and Igbo speech only works
if the phone has a Yoruba or Igbo voice; otherwise those steps show as text only.
